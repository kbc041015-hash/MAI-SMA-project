이 업로드용 사본에서는 제한 자료를 제외했으므로 자체 점검을 다시 수행한 결과가 아니다.

집계형 오답에서는 선박 코드 대신 이름을 출력하거나, 작업 행 수 대신 서로 다른 코드 수를 세거나,
부품 소모 행 수 대신 정비 문서의 플래그를 세는 오류가 관측됐다. 모델 응답과 채점 기준은 바꾸지 않았다.

이번 평가는 학생용 1,000건 DB와 예시 15문항을 대상으로 한다. 전체 200문항 평가를 완료한 것은 아니다.
절차형 인용 일치율은 답변 전체의 정확도 또는 정비 절차의 안전성을 보증하지 않는다.
집계형 응답 시간은 직전 모델 점검으로 긴 프롬프트의 캐시가 남아 있는 상태에서 측정했다.

공유 제한이 있는 문항 본문, 고정 문맥, DB, 엑셀 기록양식, 응답 원문 및 전체 로그는 이 저장소에 포함하지 않는다.
숫자 요약은 `evaluation_summary.json`에, 제공 코드의 파일 해시는 `source_hashes.json`에 있다.
